# System Health Monitor

The bash script, which monitors the basic information about the system health.

## Project journey
3october 2026:i made memory usage checker  it checks total memory available free memory and used memory 
 

## Features

 Memory usage monitoring


## Commands used

`free` - check memory usage

`grep` - grep some useful information
`awk` - pull out the information we need from commands
`df` - check disk usage
`ps` - see running processes
`wc` - count the number of processes
`uptime` - check the system uptime
## How to use


bash system_monitor.sh
